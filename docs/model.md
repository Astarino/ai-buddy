# Модель и воспроизводимость

Текущий основной вариант — **Qwen3.5 4B через Ollama 0.40.16**. Нативный
агентный промпт: `buddy-tools-v3`; адаптер ответа по источникам сохраняет
`buddy-grounded-v4`. Дообучение не проводилось. Внешнего автоматического fallback нет.

## Что проверено 16 ноября

[Текущий отчёт агента](../reports/agent-qwen.json) получен на чистом Linux CPU
в [GitHub Actions](https://github.com/Astarino/ai-buddy/actions/runs/43844812208).
Прикладной код: `f848b67c69a8a53eb81de621ab86711d49768d7c`.
Ollama ограничена 6 GiB, контекст 4096, один запрос, thinking выключен.

| Исходное состояние | Выбор Qwen | Итог |
| --- | --- | --- |
| Нет доступа | Контекст → подготовка доступа | Точная карточка, записи до подтверждения нет |
| Заявка ожидает | Контекст → поиск → ответ | Статус существующей заявки, без новой |
| Согласовано | Контекст → поиск → ответ | Согласование не названо выдачей |
| Доступ выдан | Контекст → поиск → ответ | Следующий шаг — руководство |
| Руководство изучено | Контекст → подготовка назначения | Карточка первой задачи |
| Задача назначена | Контекст → поиск → ответ | Требования ревью с доступными источниками |
| Вопрос наставнику | Подготовка вопроса | Адресат и текст для подтверждения |

**7/7 модельных решений и 7/7 итоговых состояний**, 26–81 с на случай.
Отчёт отдельно сохраняет сырой выбор инструментов, аргументы и итог приложения.
Это семь синтетических Backend-случаев, не универсальная оценка агента.
Сервер проверяет ACL, аргументы и источник, ограничивает повторы и весь цикл
(6 ответов модели, 8 инструментов, 2 минуты). Модель не имеет инструмента записи.
Невалидный формат может вызвать повтор или безопасный серверный ответ;
это отражается в `kind`, а не считается произвольным ответом модели.

На Mac M4 отдельные реальные HTTP-запросы дали подготовку доступа за 21,5 с,
назначения за 14,0 с и ответ о ревью за 19,1 с. Это отдельные smoke-проверки,
не обещание задержки. Полные нативные прогоны упирались в защиту 25% свободной
памяти; они остановлены. Основное воспроизведение качества — CPU-вариант.

## Поиск

BM25 и локальные embeddings объединяются RRF. Сначала отбираются документы,
разрешённые пользователю; версии и права проверяются снова перед доставкой.
[Сравнение](../reports/retrieval.json): 26 вопросов, из них 23 с эталонным ответом,
перефразирования, опечатки, неизвестное и запрещённые источники.

| Вариант | Recall@5 | MRR@10 | Среднее, мс |
| --- | --- | --- | --- |
| Прежний | 100% | 88,4% | 0,11 |
| BM25 | 91,3% | 78,3% | 0,39 |
| Embeddings | 100% | 89,1% | 355 |
| Hybrid | 100% | 89,1% | 303 |

ACL-утечек в наборе нет. Разница MRR с прежним поиском меньше 1 п.п.; общий
выигрыш не доказан. Прежний поиск возвращает максимум три документа, что
ограничивает сравнение. Замеры выполнены на малом синтетическом корпусе на M4.
При ошибке embeddings явно включается `bm25_fallback`; LLM не подменяется.
Индекс локальный, файл 0600; изменение и удаление документов обновляют снимок.

## Запуск и границы

```sh
sh scripts/jury.sh --check
sh scripts/jury.sh --model
```

Первый запуск: около 3,3 ГБ Qwen + 622 МБ EmbeddingGemma, дополнительное место
для образов и базы. GPU и ключ не нужны. Веса выполняются последовательно
в одном runtime; embeddings выгружаются после запроса. CPU Qwen может оставаться
до 300 с, нативная Mac — `keep_alive=0`. Для нативного запуска:

```sh
sh scripts/ollama.sh
```

Launcher использует loopback, `OLLAMA_NO_CLOUD=1`, один слот и watchdog памяти
25%. Это ограничитель, не гарантия отсутствия давления. Он не скачивает веса
автоматически. Не запускать inference одновременно с браузерным рендером на M4.
27B, 9B и fine-tuning не проверялись.

`MODEL_PROVIDER=fixture` даёт явно помеченные фиксированные ответы.
`MODEL_PROVIDER=compatible` требует явных `MODEL_BASE_URL`, `MODEL_NAME`,
серверного `MODEL_API_KEY` и разрешения `ALLOW_EXTERNAL_MODEL=true` для внешнего
адреса. Совместимый URL не гарантирует native tools: требуется отдельная проверка.
Перед внешним inference нужно подтверждение конкретного вопроса; передаются
только разрешённые публичные фрагменты, без профиля и внутренней истории.
Секретов в комплекте нет. Подробности — [run.md](run.md).

Отчёты `model-evaluation.json`, `model-holdout.json`, `model-regression.json`,
`model-problem.json` относятся к предыдущему grounded-v4 без агентного цикла.
Они сохранены как история и не доказывают текущие 7 случаев. Неудачные ранние
прогоны и остановки также не скрываются; текущий результат связан с конкретным commit.

Первичные источники: [Qwen3.5 4B](https://huggingface.co/Qwen/Qwen3.5-4B),
[Ollama](https://ollama.com/library/qwen3.5:4b),
[EmbeddingGemma](https://ollama.com/library/embeddinggemma),
[Ollama FAQ](https://docs.ollama.com/faq). Контракты проверены через Context7
и фактические запросы к закреплённому runtime.
