# Интерфейс AI Buddy

Рабочая композиция: спокойный светлый мессенджер, а не отдельный портал заявок. В центре — одна задача стажёра и разговор о ней. Справа — маршрут с зависимостями; источник открывается по месту. Основной акцент — насыщенный синий, текст почти чёрный, нейтральные поверхности и тонкие границы. Цветные круги используются только в знаке AI Buddy.

Публичные материалы: [историческая статья о дизайн-системе](https://habr.com/ru/companies/avito/articles/543450/) и [Avito Вики в портфолио AGIMA](https://www.agima.ru/projects/avitowiki/). Это ориентиры ритма, иерархии и компонентов, а не актуальная внутренняя библиотека токенов. Сгенерированные ранее картинки не используются. Шрифт, размеры, сетка и компоненты этого прототипа — наши решения.

| Ситуация | Решение | Наблюдаемая проверка |
| --- | --- | --- |
| Новый стажёр не знает, с чего начать | один ближайший шаг в приветствии и маршруте | переход к запросу доступа без знания названия инструмента |
| Найденный документ недоступен | объяснение, разрешённая инструкция, карточка запроса | закрытый текст отсутствует до выдачи |
| Пользователь совершает действие | точный ресурс, права и цель до единственной кнопки отправки | пользователь может объяснить, что произойдёт |
| Внешнее ожидание | явный бизнес-статус, отдельная проверка, независимый следующий шаг | ожидание не воспринимается как выданный доступ |
| Ответ нужно проверить | компактные ссылки на источники и панель с происхождением | документ открывается без потери разговора |
| Нет сведений | конкретное уточнение и подтверждаемый вопрос ответственному | текст не уходит коллегам автоматически |

На мобильном список контактов сворачивается, маршрут открывается кнопкой; поле ввода остаётся доступным. Диалоги удерживают фокус и закрываются Escape. Движение учитывает `prefers-reduced-motion`. Ошибки имеют действие для восстановления; пользовательский текст остаётся на месте.
